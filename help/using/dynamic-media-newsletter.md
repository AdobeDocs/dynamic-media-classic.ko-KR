# ![Dynamic Media 뉴스레터 로고](/help/using/assets/dynamic-media-newsletter-logo.png)

>[!NOTE]
>
>월간 뉴스레터는 이제 중단되었습니다. 그러나 아래의 뉴스레터 아카이브에 계속 액세스할 수 있습니다.

Adobe Experience League의 Dynamic Media 뉴스레터는 제품을 효과적으로 사용할 수 있도록 Dynamic Media 및 Adobe Dynamic Media Classic에 대해 알아보는 데 도움이 됩니다.

이 아카이브된 뉴스레터에서는 방법 비디오 및 솔루션 개요와 같은 중요한 지식 구축 리소스를 찾을 수 있습니다. 이미지 사전 설정, 뷰어 사전 설정 및 비디오 프로필과 같은 주요 기능에 대한 소개도 있습니다.
